# Last Light Galleria reboot

**C02, the curved-atrium version, is the preferred reboot.** Independent strategy, local/visibility and architecture reviews recommend adoption as a bounded native blockout. The original map remains unchanged.

Start with the [preferred AML source](level-c02.aml), [actual occupied atrium](reviews/evidence/c02/normal-preview/atrium-broad-w.png), [cutaway](reviews/evidence/c02/normal-preview/cutaway.png), [top view](reviews/evidence/c02/normal-preview/top.png), and [local plan/section](experiments/c02/layout-c02.png). [The compiled packet](reviews/compiled-handoff-c02.md) links the full evidence and frozen identity.

The west public stair now curves through 80 degrees while the existing lower G1 approach runs beside and beneath its upper end. Its tangent landing offers a direct point approach or a separate northward retreat. The observation window remains usable from a deliberate lower sidestep; it does not support the stair fight. The narrower flight and faster western reinforcement are explicit tradeoffs: the measured inspection route is 4.547 seconds quicker, with a 13.280-second gap to the western service route. These are controller measurements, not established target-game timings or balance.

Independent decisions: [strategy](reviews/compiled-strategy-c02.md), [local visibility/construction](reviews/compiled-spatial-c02.md), [architecture](reviews/compiled-architecture-c02.md). Ordinary strict-floor-gap CLI build passes at nav cell .125, and 44 author movement chains pass; independent return adds 14 changed-path walks and 492 clear lower-corridor capsule probes. The nested-roof warning was inspected as intentional interior construction. Optional UV baking was skipped because Blender is unavailable. Target-engine playtesting and multiplayer obstruction remain open.
