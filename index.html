A compiler for spaces

A level is a program.
Not a mesh.

Describe floors, walls, stairs, and how they connect. LevelSpec turns that description into a 3D place you can change and take with you.

Export GLB or glTF here. Use the CLI for FBX with Blender, or Quake BSP2 with ericw tools and a game palette.
