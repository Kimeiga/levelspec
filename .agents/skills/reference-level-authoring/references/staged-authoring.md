# Structure before detail

The shared [map-authoring workflow](../../level-authoring/SKILL.md) owns structural
blockout, enclosure, details and proportional review. This sequence does not require
separate approvals for each stage or drawings before every 3D trial.

For reference-based work, record visible walls/openings and overhead obstacles early
when they constrain circulation; defer ornamental detail. Mark deliberately deferred
elements so a circulation blockout is not mistaken for a completed reconstruction.
Cross-check major structures across relevant source views, then add enclosure and
recheck affected routes. If enclosure exposes a layout contradiction, repair the
layout rather than hiding it with local patches. Existing detailed trials need not
be retained as the active geometry merely because they are more finished.
