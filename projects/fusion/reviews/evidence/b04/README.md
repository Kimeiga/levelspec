# Frozen baseline B04

This snapshot predates the user's request for substantially more layout complexity,
shortcuts and verticality. It is retained as comparison evidence, not the final
acceptance of that expanded task.

`source.aml` matches all successful capture/check manifests. `walk-report.json`
contains the 26 directional declared-route replays. `section-checks.json` adds both
directions of the southwest arc, two stair camera traces, 31 grounded observation
placements, all ten starts and the bounded gallery study. No actual combat was run.

`capture-b04-envelope/reactor-supports.png` is an uninformative attempted camera
inside the bioshield. It is retained as an original failed view, not support-contact
evidence. The corrected view is in `capture-b04-sections/reactor-supports.png`.
The initial `power-hall-b.png` is a free camera above the ramp; the grounded
replacement is `capture-b04-sections/b-entry-grounded.png`.

All perspectives include physical roofs. The overview deliberately hides roofs.
The baseline build emitted 194 navigation-island warnings and four ramp open-side
warnings. Their locations and dispositions remain in the diagnostic and review files.
