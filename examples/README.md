# Maintained examples

- [Daiban](daiban.aml): bounded native courtyard study with multilevel circulation. Dimensions are estimates; it does not establish whole-building reference fidelity.
- [Dust II](dust2.aml): approximate playable CS2 blockout with independently checked elevation, collision and route contracts. See [reference notes](../reference/dust2/README.md).

Validate, preview or build either AML source with the repository-local CLI. Feature and migration inputs live under `tests/fixtures/`; the project starter belongs to `src/cli/templates/`. Sources use meters and right-handed Z-up coordinates.
