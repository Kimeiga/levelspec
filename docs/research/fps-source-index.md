This counts publications, not independent studies or independent authors. Article sections, before/after images, and mirrors are not counted separately. A located video/talk is a viewing recommendation; see the linked annotation file for what was actually inspected. Multiple sources from one publisher and repeated underlying examples should not be interpreted as independent confirmation.
