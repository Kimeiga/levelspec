# Organic layout review

Review the plan's underlying spatial order while alternative organizations are
still feasible. The [workflow](../../fps-map-workflow/SKILL.md) assigns this scope
to an independent agent alongside spatial interest. This assignment evaluates
layout composition at sketch scale. Enclosure, reachability and competitive play
have their own review scopes.

## Independent first pass

Take the raw brief, labeled plan, relevant levels or sections, observed image
references and available alternatives. Inspect them before reading author rationale
or other verdicts. Treat explicit user and source constraints as part of the brief.

- Mark where masses, route axes, widths, spacing and junctions repeat across the
  plan. Trace a representative journey through those areas. Inspect actual
  boundaries, thresholds and playable space, including repetition inside a
  rotated or irregular outer footprint.
- Connect the order you see to evidence about site, program, construction or
  circulation. Identify where a repeated module makes sense and where it appears
  to dictate the experience without a reason in the place. A well supported
  rectilinear grid is a valid outcome, including across the whole map.
- If the order is weak, propose a concrete alternative at the affected scale.
  Locate it on the drawing and identify what moves, widens, bends, merges or
  changes adjacency, plus the constraint that motivates the change. Describe how
  the journey would change and what the alternative costs in legibility,
  circulation or retained gameplay anchors. Keep useful repeated bays and alignments.

Use the [layout order guidance](../../fps-map-workflow/references/node-to-space.md#layout-order)
for examples. Judge the resulting spatial relationships. A curved corner or an
angled wall can leave the same repeated playable arrangement intact.

## Return to the author

Return **promising** when the order is supported, **rework** when unsupported
repetition shapes a consequential part of the plan, or **unclear** when the drawing or
evidence cannot establish the relationship. Name the inspected revision, mark
the affected regions or routes, and explain the reason. Give a focused alternative
for rework, or request the specific missing view or reference for unclear. Judge
both orthogonal and irregular proposals by how they serve the place and the brief.
