# Principles recorded for future authoring

The portable source of instructions is [nodes to spaces](../../../.agents/skills/fps-map-workflow/references/node-to-space.md), linked by all four FPS skills. This record distinguishes reusable guidance from which optional examples this prototype happens to use.

| User direction | Reusable workflow/skill behavior | Current-map application or remaining option |
|---|---|---|
| Start with nodes, sites, spawns and purposeful edges | Name callout sections and purposeful connections early, before dependent geometry; the graph can share a spatial sketch; distinguish movement, observation and support | Nineteen-space graph, offset spawn anchors, explicit route roles |
| Avoid huge arena filled with arbitrary props | Shape routes, building masses and negative space; report occupied/walkable area as a diagnostic without a majority quota | Service-building wings shape west/east passages, site contours and Splitter |
| Both long LOS and camping/FOV concerns | Sample supported XYZ positions and spawn areas; list entry-frontier widths/levels; warn and adjudicate | Repeatable grid scan, protected spawn and elevated-area probes, scoped warning reviews |
| Long sightlines can be intentional | Keep justified long lanes; do not use thresholds as automatic map pass/fail | Remaining cross-region65m warning prompted an architectural Elbow repair; no35m universal cap |
| Plan heights/FOV before3D, inspect again after3D | Sections, eye/body/FOV assumptions, tall occluders, same actual paired views after compile |8–9m masses and planned/compiled gallery/approach checks |
| More usable low cover | Distribute preparation, ducking, reposition and retreat cover; inspect standing/low eye/body relationships | Thirteen low features, including three gallery positions; static posture rays differ as intended |
| Props still useful in open areas | Mix architecture and freestanding cover for tactics, orientation and visual character; no prop quota or ban | Central A01/B01 retained; low features remain instead of removing all props |
| Meaningful elevation | Compare flat, broad grades, local steps/crests and stacked options; flat maps remain valid | A+.6 stairs/dais, east+1.2 approach crest and4m gallery; broad district grades remain a future option |
| Parallel ascending third branch | Derive a3D junction from graph, inspect ascent/body/eyes/support/reverse approach | S01 climbs parallel to Mid before joining upper gallery |
| Upper-room observation window | Separate sight edge from movement edge; bound aperture, exposure, access and counterplay | Recorded as optional pattern; no requirement to add a window to every map |
| Curves/diagonals/nonrectangular rooms | Use meaningful non-grid shapes with full turn clearance and readable composition | Diagonal industrial-wing corner, contoured sites and dogleg gallery; curves remain an option |
| One-way movement / unguarded edges | Optional/forced drop, landing, exposure, cost, return and actual mechanics; do not rail everything or fabricate links | Marked D01four-meter optional drop; normal routes remain; target-engine falling/damage unverified |
| Whole-map plus local/boundary agents | Macro graph/rotations/attack views plus small named-section packets; independent first reads, reconciled repairs/rechecks | Macro reviews and focused Reservoir/Elbow/gallery scopes, multiple layout and compiled rounds |
| Odd holes/orphan topology | Inspect intended openings and playable-room connections; distinguish inaccessible scenic masses | Apertures are not automatic walking links; building masses intentionally inaccessible |
